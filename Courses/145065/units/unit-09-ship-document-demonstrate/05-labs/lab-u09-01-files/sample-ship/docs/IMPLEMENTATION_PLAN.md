# Implementation plan · Line 3 Sensor Monitor 1.0.0

## What is being installed

The Line 3 Sensor Monitor, version 1.0.0, from the release folder built with `dotnet publish`.

## Steps

1. Copy the whole release folder to `C:\Line3Panel\` on the panel PC.
2. Start `Line3.Hmi.Panel.exe`. You should see the header LINE 3 SENSOR MONITOR within five seconds.
